# Техническое задание: OFZ Assistant Pro

## 1. Общая концепция
Создание готового продукта для массового пользователя (непрограммиста). Продукт состоит из двух частей:
1. **Дашборд (Пульт управления)** — Windows-приложение (PyQt5), которое устанавливается на ПК. В нем пользователь настраивает токены, расписание, смотрит отчеты.
2. **Облачный движок (Бот)** — Python-скрипт, который работает на GitHub Actions по расписанию, торгует ОФЗ и сохраняет отчеты в репозиторий.

## 2. Дашборд (Пульт управления)
- **Интерфейс:** Темная боковая панель с меню (Статус, Календарь, Расписание, Настройки, Создать портфель).
- **Безопасность:** Ввод токенов (Т-Инвестиции, GitHub PAT). Сохранение токенов локально в файл `local_settings.json` (файл в `.gitignore`).
- **Связь с GitHub:** Отправка настроек в `config.json` через GitHub API.
- **Отображение статуса:** При запуске автоматически подтягивает последний отчет с GitHub, группирует активы (Акции, Облигации, Другие, Деньги) и выводит крупным шрифтом.
- **Календарь:** Просмотр отчетов за любой день. При клике на дату загружается JSON-отчет.
- **Расписание:** Настройка периодичности через интерфейс в стиле cron-job.org (радиокнопки "Каждые N минут", "Каждый день в", "Каждые N месяцев" с выпадающими списками часов и минут). Сохраняется в формате cron.

## 3. Облачный движок (main.py на GitHub)
- **Запуск:** По cron-расписанию или вручную (workflow_dispatch).
- **Чтение конфига:** Берет флаг `create_portfolio` и расписание из `config.json`.
- **Аудит портфеля:** Собирает полный список активов (акции, облигации, фонды, валюта) с ценами и количествами.
- **Генерация отчетов:** Сохраняет JSON-отчет в папку `reports/` и пушит его в репозиторий (создавая коммит от имени GitHub Action).
- **Логика покупки (в разработке):**
  - Если флаг `create_portfolio = true` и портфель пуст, и баланс >= 6000 руб., бот должен купить 6 длинных ОФЗ (погашение >= 7 лет), чтобы покрыть все 12 месяцев купонными выплатами.
  - Если флаг `false`, бот докупает ОФЗ из уже имеющихся в портфеле (по текущему алгоритму).
